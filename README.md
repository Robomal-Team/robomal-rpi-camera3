# Robomal Raspberry Pi Camera 3

Setup and testing scripts for Raspberry Pi Camera Module 3.

## Supported Cameras

- Raspberry Pi Camera Module 3
- Raspberry Pi Camera Module 3 Wide
- Raspberry Pi Camera Module 3 NoIR
- Raspberry Pi Camera Module 3 Wide NoIR

## Tested Environment

- Raspberry Pi
- Debian GNU/Linux 13.7 (trixie)
- Sony IMX708
- Raspberry Pi Camera Module 3 Wide NoIR
- Python 3.13.5
- libcamera 0.7.2
- libpisp 1.7.0

wget -qO- https://raw.githubusercontent.com/Robomal-Team/robomal-rpi-camera3/main/install.sh | bash
